# Как установить бота на сервер — кратко

Краткая памятка по установке на Debian 12. Подробности, устройство и решение проблем описаны в [deploy.md](deploy.md).

## Перед началом

- A-запись домена (например, `bot.example.com`) указывает на IP сервера.
- Порты **80** и **443** открыты в панели хостинга. Порт 80 нужен Let's Encrypt для выдачи и продления сертификата.
- Под рукой токен бота MAX.
- **Локальный `npm run dev` с тем же токеном остановлен.** Продакшен регистрирует webhook, и локальный бот будет с ним конфликтовать. Для разработки лучше завести отдельного тестового бота.

## Установка

**1. Скопируйте скрипт на сервер.** Репозиторий приватный, поэтому скачать скрипт по ссылке не получится. Скопируйте его с компьютера (PowerShell):

```powershell
scp "H:\OneDrive\Документы\dev\mxbt-Autoscoring\deploy\install.sh" root@<IP>:/root/
```

**2. Запустите на сервере:**

```bash
ssh root@<IP>
DOMAIN=bot.example.com EMAIL=you@example.com bash /root/install.sh
```

Если включить `ENABLE_UFW=1`, скрипт ещё и настроит файрвол: оставит открытыми SSH, 80 и 443.

**3. По ходу работы скрипт дважды попросит ваших действий:**

- **Deploy key.** Добавьте показанную строку `ssh-ed25519 AAAA…` в GitHub: репозиторий **mxbt-AutoScoring → Settings → Deploy keys → Add deploy key**. Галочку *Allow write access* не ставьте. Затем нажмите Enter в терминале.
- **Токен бота.** Вставьте токен, ввод не отображается. Он сохранится в `/etc/mxbt-autoscoring/env`.

**4. Проверьте результат.** Скрипт закончится строкой `✅ Готово: https://bot.example.com/health отвечает`. Напишите боту `/start` в MAX.

## Что делает скрипт

- Ставит Node.js 24, nginx и certbot (сертификат Let's Encrypt с автопродлением).
- Создаёт пользователя `mxbt` и службы systemd `mxbt-bot` и `mxbt-mocks`.
- Бот сам регистрирует webhook MAX и слушает только `127.0.0.1`. Наружу через nginx по HTTPS открыто только то, что нужно MAX и эквайеру.
- Скрипт можно запускать повторно: сделанные шаги пропускаются, секреты и сертификат не перезаписываются.

## Потом

```bash
journalctl -u mxbt-bot -f                          # логи
systemctl restart mxbt-bot                         # перезапуск
bash /opt/mxbt-autoscoring/app/deploy/update.sh    # обновление до последней версии main
REF=<коммит> bash /opt/mxbt-autoscoring/app/deploy/update.sh   # откат
```

## Важно

- **Внешние сервисы пока mock-сервисы.** Цены условные, оплата идёт через тестовую страницу без списания денег, сессии теряются при перезапуске. До приёма настоящих клиентов пройдите чек-лист [«Перед реальным запуском»](deploy.md#перед-реальным-запуском).
- Если что-то упало, сохраните вывод скрипта и посмотрите [«Частые проблемы»](deploy.md#частые-проблемы).
